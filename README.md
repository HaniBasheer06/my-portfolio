# My Portfolio

A simple responsive portfolio website built with HTML, CSS, and JavaScript.

## Folder Structure

- `index.html` - Main portfolio page
- `css/style.css` - Website styling
- `js/script.js` - JavaScript
- `assets/` - Images and resume

## How to Run in VS Code

1. Extract the ZIP file.
2. Open the `my-portfolio` folder in VS Code.
3. Open `index.html`.
4. Use the **Live Server** extension, or open `index.html` directly in a browser.

## Customize

Replace these files in `assets/` with your own:
- `profile.jpg`
- `project-movie.jpg`
- `project-security.jpg`
- `resume.pdf`

Also edit `index.html` to add your name, email, skills, and project details.
